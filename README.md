# Corleone Forged

A comprehensive frontend solution for the **Corleone Forged** wheel brand. This project includes the official website, wheel configurator, landing pages, mobile interface, email templates, and supporting assets. It was developed using HTML, CSS, Bootstrap, JavaScript, jQuery, and PHP with a focus on responsiveness, performance, and user experience.

> **Project Status:** Completed  
> **Development Year:** 2021

---

## Project Overview

Corleone Forged is a complete web solution designed to showcase forged wheel collections while allowing customers to customize wheel designs through an interactive configurator.

The project consists of multiple frontend applications that share a common design system and asset library.

---

## Features

### Official Website
- Fully responsive design
- Product showcase
- Multiple homepage layouts
- Contact pages
- Dealer information
- Gallery
- Optimized for desktop, tablet, and mobile devices

### Wheel Configurator
- Interactive wheel customization
- Dynamic color selection
- Multiple wheel models
- Component selection
- Real-time preview
- Product-specific configurations

### Landing Pages
Dedicated landing pages for different wheel categories:
- Concave Forging
- Dually Forging
- Monoblock
- Off-Road Forging
- Standard Series
- Category Pages

### Mobile Version
- Mobile-friendly interface
- Responsive navigation
- Optimized layouts
- Touch-friendly controls

### Email Templates
Professional email templates including:
- Dealer Application

- Payment Application
- Product Information
- Customer Review Request
